SourceTrail

Where did I get that number from? Trace a claim to its evidence.

View on GitHubInstall

Open source · MIT license · runs on your machine

What it does

SourceTrail indexes your PDFs, Word, Excel and text files locally. Give it a claim and it shows the exact page, cell or line that supports it, and warns when another file gives a different number. It does not ask an AI about your files: it takes you back to the original evidence.

Exact locations
PDF page, Word paragraph, text line, Excel cell.
Spots disagreement
Different numbers in different files.
Local SQLite
Your files never leave your machine.
Incremental
Only changed files are re-read.

Example

$ sourcetrail trace "The model achieved 92% accuracy"
CLAIM:
The model achieved 92% accuracy

Sources:
1. Research_Paper.pdf  (supports)
   page 2
   "The model achieved 92% accuracy on the held-out test set."
2. Experiment_Report.xlsx  (supports)
   sheet Results, cell B2
   "Accuracy Value 92%"
3. Old_Notes.docx  (gives a different number)
   paragraph 1
   "In the first run the model reached 89% accuracy on validation data."

Evidence Status: CONFLICTING
Sources disagree on the number. Check which one is the original.

Install

git clone https://github.com/mohamed-elshamy-ai/sourcetrail
cd sourcetrail
pip install -e .
sourcetrail add ~/Research
sourcetrail trace "The model achieved 92% accuracy"

How it works

  1. Split each file into passages with a citable location and store them in SQLite full-text search.
  2. Take the meaningful words and numbers of your claim.
  3. Find passages sharing the words.
  4. Same numbers means supports. Different numbers of the same kind means differs.
  5. Report the status with every source.

Limits

  • Matching is by shared words and numbers, not meaning. Read the quoted sentence.
  • SUPPORTED does not prove a claim is true.
  • No OCR for scanned files, no embeddings or entity extraction yet.
  • Claims without numbers only get MENTIONED or NOT FOUND.
